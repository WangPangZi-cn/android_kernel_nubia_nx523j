# android_kernel_nubia_nx523j

Linux 3.10.108 kernel for **Nubia Z11 Max (NX523J)** (MSM8976), used for a
working LineageOS 18.1 (Android 11) build.

Same lineage as `github.com/nubia-development/android_kernel_nubia_msm8976`
(branches up to `nubia_msm8976_q-dev`); this snapshot is the exact tree used
for the 18.1 build (TWRP reports `3.10.108-mokee`). Commit-level mapping to
the upstream repo was not preserved (non-git snapshot) — treat this repo as
the authoritative source for the 18.1 ROM.

No local kernel modifications were required for Android 11 on nx523j.
